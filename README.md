## 🚀 Como Utilizar

### Instalação (versão Instalador)

1. Execute o arquivo `Mathematics for Data Science Laboratory Setup 1.0.0.exe`
2. Escolha o **diretório de instalação** (ou mantenha o padrão)
3. Selecione se deseja criar **atalhos** na área de trabalho e no menu Início
4. Clique em **Instalar** e aguarde a conclusão
5. Abra o aplicativo pelo atalho criado

### Versão Portátil

1. Extraia/baixe o arquivo `Mathematics for Data Science Laboratory-Portable.exe`
2. Dê dois cliques no arquivo para executar
3. Pronto — nenhuma instalação é necessária

### Primeiros Passos

1. Abra o **Mathematics for Data Science Laboratory**
2. Explore o **Dashboard** inicial (categorias e busca global)
3. Escolha um laboratório (ex.: Gradiente Descendente, PCA, Teorema de Bayes)
4. Configure os **parâmetros** de forma interativa
5. Clique em **Executar** para ver o resultado com:
   - Fórmula matemática
   - Cálculo passo a passo
   - Resultado numérico
   - Descrição conceitual
   - Dados JSON exportáveis

### Configurações

- **Tema**: escuro (padrão) ou claro
- **Precisão numérica**: de 2 a 15 casas decimais
- **Execução automática** e **animações**

## 🧪 Laboratórios Disponíveis

### Álgebra Linear
Vetores, Matrizes, Determinantes, Autovalores e Autovetores, Decomposições (LU, QR, SVD)

### Cálculo
Derivadas, Taxa de Variação, Derivadas Parciais, Gradiente, Hessiana, Integrais

### Probabilidade e Estatística
Probabilidade, Teorema de Bayes, Estatística Descritiva, Distribuições, Amostragem, Lei dos Grandes Números, Teorema Central do Limite

### Otimização e Machine Learning
Otimização, Gradiente Descendente 2D e 3D, Funções de Perda, Regularização (L1/L2/Elastic Net), Regressão Linear, Regressão Logística, Matemática de Redes Neurais, Funções de Ativação, Backpropagation, PCA
